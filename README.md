# SurakVault
Local File & Password Vault Application Using Python and TkInter

## Features

### File Vault
- Encrypt and Decrypt files securely using a master password.
- Maintain a list of encrypted files.
- Delete files from the vault safely.

### Password Vault 
- Store and manage website/app credentials.
- Search, add, delete, and copy password entries.
- Option to show or hide passwords.

## Requirements
Install the required Python Packages:

```bash
pip install pyperclip cryptography
```

## Installation
1. Clone this repo
```bash
git clone https://github.com/YunchoHang/SurakVault.git
cd SurakVault
```

2. Create a virtual environment (Optional):
```python
python -m venv venv
source venv/bin/activate # Linux
venv\Scripts\activate # Windows
```

3. Run the Application
```python
python main.py
```

Download the Windows executable here: [SurakVault.exe](https://github.com/YunchoHang/SurakVault/releases/tag/v1.0)
